Шелковый путь олимпиада по математике 2011 года | Казахстанские олимпиады

Источник: https://olympiads.bc-pf.org/math/s/srmc/2011/problem1

Определите наименьшее возможное значение \(|A_1 \cup A_2 \cup A_3 \cup A_4 \cup A_5|\), где \(A_1, A_2, A_3, A_4, A_5\) множества, одновременно удовлетоворяющие следующим условиям:
(i) \(|A_i \cap A_j|= 1\) для всех \(1 \le i < j \le 5\), т.е. любые два различных множества содержат ровно один общий элемент;
(ii) \(A_i \cap A_j \cap A_k \cap A_l = \emptyset\) для всех \(1 \le i < j < k < l \le 5\), т.е. любые четыре различных множества не содержат общего элемента.
Здесь \(|S|\) означает количество элементов множества \(S\).
