Источник: https://olympiads.bc-pf.org/math/s/apmo/1991/problem3

\(a_1\), \(a_2\), \(\dots\), \(a_n\), \(b_1\), \(b_2\), \(\dots\), \(b_n\) —
положительные вещественные числа такие, что \(a_1 + a_2 + \dots + a_n = b_1 + b_2 + \dots + b_n\). Докажите, что

\[\frac{{a_1^2}}{{{a_1} + {b_1}}} + \frac{{a_2^2}}{{{a_2} + {b_2}}} + \dots + \frac{{a_n^2}}{{{a_n} + {b_n}}} \geq \frac{{{a_1} + {a_2} + \dots + {a_n}}}{2}.\]
